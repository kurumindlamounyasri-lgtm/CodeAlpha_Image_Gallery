# CodeAlpha Image Gallery

A responsive image gallery built using HTML, CSS, and JavaScript.

## Features

- Responsive CSS grid layout for desktop, tablet, and mobile.
- Image hover effects and smooth transitions.
- Lightbox image viewer.
- Next and Previous navigation in the lightbox.
- Escape key closes the viewer; arrow keys navigate images.
- Category filters: All photos, Nature, Architecture, Travel, and Little details.
- Lazy-loaded images and descriptive alt text.

## Project files

- `index.html` — page structure and lightbox markup
- `style.css` — layout, styling, hover effects, responsive breakpoints
- `script.js` — image data, filtering, and lightbox navigation

## Run locally

1. Extract the project folder.
2. Open `index.html` in a modern browser.
3. An internet connection is needed to load the sample photos from Unsplash and the optional Google Fonts.
4. Click a photo to open the lightbox. Use the arrow buttons or keyboard arrow keys to navigate.
5. Select a category to filter the gallery.
